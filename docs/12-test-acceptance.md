# 12. 测试计划与验收标准

## 1. 测试层级

- 单元测试：状态规则、金额计算、电话号码规范化、权限判断、模板映射、公共 DTO 字段白名单。
- 集成测试：数据库约束、递归品类查询、登录/角色/权限、上传流水线、队列任务和删除重试。
- E2E：浏览器登录、产品浏览、批量选品、WhatsApp 跳转、后台商品维护、商品报价与 PI Excel 导出、客户电话查重。
- 安全测试：未授权访问、越权、CSRF/XSS、SQL 注入、文件上传绕过、路径穿越、公式注入、秘密泄漏。
- 响应式测试：360px 手机、常见平板尺寸、桌面宽屏；真实浏览器测试至少覆盖 Chromium，并按实际市场补 Safari/WebKit。

## 2. 关键验收用例

### 前台
- 首页正确显示精选、新品、预售区块；草稿/下架/默认隐藏停产商品不出现。
- 产品列表按任意层级品类过滤时包含后代产品，搜索、分页、排序结果稳定。
- 详情展示规格、包装、箱规、图片和标签；HTML 源码、Network JSON、SEO Meta、JSON-LD、缓存响应均无内部价格。
- 访客勾选多商品，切换分页/详情后清单保留；WhatsApp 文本包含所有已选 SKU；超过上限有明确阻止/分批提示，不会静默丢 SKU。
- 所有页面在 360px 宽度可用，无关键内容横向溢出；键盘可操作表单和弹窗。

### 后台和权限
- 无账号注册入口；错误登录限流；禁用账号立即不能使用管理 API。
- 仅有 `product.read` 的用户不能创建/编辑/删除/导出；直接调用 API 仍然被拒绝。
- 中英文切换覆盖菜单、表格、表单、空态、错误、确认弹窗和任务状态。
- 品类移动阻止环；有子类/商品引用时禁止直接硬删除。
- SKU 重复、非法尺寸、负重量、无效箱规、错误图片格式、非法 URL 均被拒绝并给出明确错误。
- 图片伪造 MIME、损坏或截断、超大像素和超大字节由服务端拒绝；仅有合法文件头但
  Sharp 无法真实解码的图片必须停留在失败状态，不能关联商品或发布。
- 合法图片生成不超过原图宽度的 320/640/1280 WebP；默认不生成 AVIF。前台卡片、
  详情图库和询价缩略图使用 `srcset/sizes`，不下载原图再缩小。
- 公共商品图 URL 含 asset id 与内容版本；图片替换后 URL 改变，未发布、删除中或
  版本不匹配的图片返回 404。商品源图、报价模板、PI 与报价导出不可从公共图片路由读取。
- 商品图物理删除必须同时删除源对象和所有 WebP variants；任一派生对象删除失败时
  任务保持 FAILED/可重试且写失败审计，不能假报成功。
- R2 presigned PUT 必须使用服务端生成的随机 key；确认完成后 API 通过 HEAD 复核对象
  大小和 Content-Type，再写入持久化 Sharp 任务。私有 bucket 不得匿名读取。
- 多个 PostgreSQL runner 并发 claim 不得重复领取；执行中持续 heartbeat，崩溃后租约
  过期可恢复；达到最大次数后进入 FAILED 并保留人工重试能力。

### Excel/PI
- Excel 转 PDF 页面在中英文 Admin Shell 中可用；`excel_pdf.create/read/download/retry/delete`
  逐接口由服务端 RBAC 校验，未登录 401、无权限 403，菜单隐藏不能替代授权。
- Admin 按 8 MiB 分块上传；恰好 200 MiB 可初始化，超过 1 字节被拒绝。缺块、长度或完整
  SHA-256 不匹配、并发重复初始化时不会创建重复任务；单块请求始终低于 Next.js 10 MiB 限制。
- 上传仅接受无宏 `.xlsx`；伪装扩展名、损坏 ZIP、宏/外链/OLE/ActiveX/外部数据连接、
  加密工作簿、entry 数/单 entry/展开总量/压缩比超限均明确拒绝，且不调用 LibreOffice。
- Worker 使用固定参数和无 shell 的隔离 LibreOffice profile；任务持久化在 PostgreSQL，
  使用 attemptId/leaseOwner 条件更新。双 Worker 竞争、Worker 重启和过期租约恢复不会产生
  重复成功状态，旧 attempt 不能覆盖新任务结果。
- 成功 PDF 通过文件签名、大小、页数、EOF 和 `pdfinfo` 校验；失败或超时任务不产生可下载
  文件。下载必须 owner/data scope 与 `excel_pdf.download` 双重校验，响应为 private/no-store，
  Storage 对象缺失或大小不一致时不能成功下载。
- 删除会撤销下载并持久化输入、输出和分块的物理删除任务；失败可重试，审计不含 storageKey、
  工作簿内容、客户资料或完整临时路径。过期任务由 cleanup 幂等清理。
- 验证报价单与 PI 金样本的打印区域、分页、图片、字体、合并单元格和金额；记录 LibreOffice
  版本/镜像 digest。接近 200 MiB 的脱敏 XLSX 需在 staging 完成上传、转换、RSS/CPU/磁盘和
  300 秒超时容量验收，不能用自动化单测替代真实转换压测。
- 模板字段缺失会阻止启用或导出并显示错误位置。
- 按品类导出包含正确后代；模板版本和筛选快照保存在记录中。
- 导出任务失败可重试；删除时文件和记录最终均不存在，临时失败可自动重试并可监控。
- PI 服务端重算行金额与总额；币种、小数位、舍入和修订版本正确；历史 PI 不受产品主数据更新影响。
- 200 MB 级商品 Excel 按 8 MB 分块上传，任一块可独立重试；完整 SHA-256/长度不匹配时
  Worker 进入 FAILED，不解析或提交。
- local 存储模式下图片文件实际位于仓库根目录 `.data/uploads`；PostgreSQL validation
  JSONB 小于 100 KB，且不包含 bytes、Base64 或 `"type":"Buffer"`。
- `凡士林.xlsx` 前两行验收必须提取两张图片、分别关联两个 SKU/B2 与 B3 对应商品行并各设封面。
- 全部行有效时一次创建全部商品；第二行无效或提交时发生 SKU 竞争，整批新增数为 0。
- 同一 validationId 第二次 commit 返回冲突且不新增商品；过期上传、validation 与无引用
  staging 图片可由 cleanup job 幂等清理。
- 上传过程中客户端断开返回/记录 408 而不是 500；单块超过限制或请求体超限返回 413。

### WhatsApp 客户与分析
- 电话格式化后识别重复客户；同一客户可创建多条接待活动，历史不会被覆盖。
- 并发新增同一号码不会创建两个主档；冲突后提示并保留用户输入。
- 电话搜索框可按规范化号码查找；无匹配与多个模糊匹配状态清楚。
- 实时活跃人数严格遵循 5 分钟心跳定义；国家未知可显示；VPN/GeoIP 误差不作为精确地址。
- 访问统计 API 受限流保护；事件提交不接受电话、邮箱等任意 PII 字段。

### 部署/运维
- 数据库从空库迁移成功；升级迁移在 staging 通过。
- 备份文件可以恢复到隔离环境；记录恢复时间和验证结果。
- health/readiness、队列积压、转换失败、文件删除失败均可监控。
- 恢复/回滚步骤由非原作者根据文档执行成功。

## 3. 发布准入（建议）

- 所有 P0/P1 缺陷关闭；无已知价格泄漏、越权、严重上传漏洞或数据丢失风险。
- lint、typecheck、单测、集成测试、E2E 主路径与 production build 全部通过。
- 核心迁移已审查，备份/回滚策略确认。
- 响应式、英文文案、后台中英双语、SEO 和访问隐私说明检查完成。
- 已有监控、告警和故障联系人/处理流程。
