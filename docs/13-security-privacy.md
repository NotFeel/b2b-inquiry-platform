# 13. 安全、隐私与价格隔离

## 1. 主要安全控制

- 所有域名强制 HTTPS；配置 HSTS、Content-Security-Policy、X-Content-Type-Options、Referrer-Policy 等安全响应头，并按实际资源来源调试 CSP。
- 登录：强密码策略、哈希存储、限流、临时锁定、Session 轮换、退出失效；后台默认不提供注册。
- 授权：服务端 RBAC；每个管理端点按权限校验；对象级操作校验租户/范围（若未来新增租户）。
- 输入：DTO schema、ORM 参数化查询、HTML sanitizer、URL 协议白名单；避免将用户输入拼入 SQL/命令行。
- 文件：扩展名/MIME/签名多重校验，随机 key，大小/数量/像素限制，隔离 Worker，最小权限对象存储，无公共可猜路径。
- 任务：资源限额、超时、重试上限、幂等、失败告警；PDF 转换不与主 API 同容器高权限运行。
- 审计：账号、角色/权限、产品发布/下架、模板维护、PI 导出、批量删除和客户数据导出等操作记审计。

## 2. 价格绝不公开

内部价格字段示例：`price_cny`。它只能出现在有授权的后台 API 和受控报价/PI 处理逻辑中。

必须保护的泄漏面：
- 公共 REST JSON、SSR/静态生成页面数据、HTML source、React hydration payload。
- 搜索索引、公共缓存、CDN、sitemap、Open Graph、JSON-LD、分析事件、错误日志。
- 公共接口的对象展开/序列化、通用共享 Product DTO、客户端状态持久化。

建议机制：独立公共 DTO；公共查询显式 select 白名单字段；CI 负向测试确认 `price_cny`/`unit_price` 不存在；上线时用测试 SKU 的唯一内部金额在页面源代码和 Network 中搜查。不能以 CSS 隐藏作为防泄漏方案。

## 3. 客户与访客隐私

- 客户电话号码和备注属于受限个人信息；只对业务需要的角色开放，导出独立授权，展示时可按角色遮挡部分号码。
- 访客分析默认不长期保存原始 IP；GeoIP 后只保留国家/地区代码与汇总指标，保留期限在配置中明确。
- Cookie/追踪是否需要 consent，应结合目标国家/地区和部署方式由业务/法务确定；不能假设一个全球通用规则适用所有访客。
- 隐私声明需说明分析数据、用途、保留时长、第三方 GeoIP/存储供应商和联系途径。
- 客户删除/更正请求需定义流程；审计记录应避免不必要复制被删除的个人信息。

## 4. Excel 与命令执行安全

- 不执行用户上传的 Excel 宏、外部链接、数据连接或嵌入对象；转换器在隔离容器内运行。
- 不将文件名直接拼到 shell 命令；调用进程使用固定参数和安全路径。
- 防公式注入：导出用户可控文本时转义可能被表格软件识别为公式的前缀字符。
- Excel/PDF 只允许授权用户下载；签名链接短时有效且避免写入分析日志。

## 5. 供应链与秘密管理

- 锁定依赖版本与 lockfile；自动安全扫描；高风险依赖更新必须经过测试。
- 生产密钥从平台 Secrets Manager/环境变量注入；定期轮换；最小权限、分环境独立。
- 不在 Git、文档示例、Issue、日志中出现真实密码、Token、客户号码或生产文件。
